
# TestForge — QA Testing & Defect Intelligence Dashboard

TestForge is a responsive software testing dashboard built with HTML, CSS and JavaScript. It helps students and QA interns manage test cases, record defects, track test execution and export reports.

## Features

- Add, edit and delete test cases
- Mark tests as Pass, Fail, Blocked or Not Run
- Record software defects and reproduction steps
- Track defect severity and status
- Live testing statistics and execution progress
- Search and filter test cases
- Export test cases and defects to CSV
- Save records using browser local storage
- Responsive desktop and mobile layout
- Demo data included

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- CSV export

## Run locally

1. Download or clone this repository.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Add test cases and defects.
4. Refresh the page to verify local saving.

No package installation, API key or backend server is required.

## Deploy with GitHub Pages

1. Push these files to your GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder.
5. Click Save and open the published URL when deployment finishes.

## Data storage note

Records are saved in the browser on the current device. They are not automatically shared between users or browsers. Clearing browser storage may remove the records.

## Project purpose

This project demonstrates frontend development, CRUD operations, client-side data persistence, test management, defect tracking, filtering, reporting and responsive UI design.
